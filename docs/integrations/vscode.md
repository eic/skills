# VS Code integration

## Recommended flow

1. Clone this repository.
2. Select definitions from a pack.
3. Adapt chosen agent and skill content into:
   - workspace instructions
   - reusable prompt files
   - repository contribution guidance

## Mapping guidance

- `spec.purpose` and `spec.instructions` -> Copilot custom instructions.
- Skill procedure steps -> task-specific prompt files.
- Constraints -> explicit guardrails in workspace-level guidance.

## Maintenance

- Refresh from upstream releases.
- Re-run validation after local updates.
